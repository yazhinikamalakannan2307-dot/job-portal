# 💼 Job Portal

A modern, responsive job portal application built with React that allows users to search, filter, and bookmark job listings with a beautiful dark/light theme.

## ✨ Features

- 🔍 **Search Jobs** - Search by title, company, or skills
- 🎯 **Filter Jobs** - Filter by role and location
- ⭐ **Bookmark Jobs** - Save favorite jobs for later
- 🌙 **Dark/Light Mode** - Toggle between themes with smooth transitions
- 🎨 **Beautiful UI** - Teal, purple, and sky-blue gradient theme
- ✨ **Animated Background** - Floating orbs, particles, and shooting stars
- 📱 **Responsive** - Works on all devices
- 💳 **Glassmorphism** - Modern glass effect design
